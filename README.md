# DDD Psychology Clinic

Hi! I'm learning Domain-Driven Design, and this repository is where I practice it, modelling a psychology clinic.

## Why

I wanted to practice DDD in Python, but most of the DDD material I found is written in Java, C# or TypeScript, and there isn't much of it in Python. So I decided to write my own, and to make it public in case it helps someone else on the same path.

## Heads up: I'm learning

This is not a reference implementation. I'm learning as I go, so there will be mistakes, things I'll change my mind about, and decisions that someone with more experience would make differently.

If you know more about DDD and you see something wrong, or something you would do another way, please tell me. Opening an issue is perfect, and I'd really appreciate it.
